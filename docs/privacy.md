# 公开资料与数据处理说明

## 公开内容

本仓库发布可复用的 Skill 指令、Python 客户端、接口契约、合成测试和打包工具。以独立目录和新的 Git 历史发布，不携带开发仓库的历史版本。

测试数据用于验证文件名解析、授权、幂等性、任务归属、结果投影和下载行为。文件内容、报告正文、句柄、日期、文件名与网址均为测试夹具，不是研究成果、真实用户档案或线上调用证据。

## 未包含的内容

- 原始研究文档、企业材料、报告附件、业务数据库与知识库。
- AI 对话原文、会话导出、个人工作约定、开发交接和运行日志。
- 真实部署域名、平台账号及项目编号、原始任务标识与下载签名。
- 联系方式、个人设备路径、账号密钥、Cookie、访问令牌和本地凭证文件。
- 原始 Git 历史、开发缓存、临时文件和旧版安装包。

## 发布方式

公开文件按明确清单选取；示例中的历史业务信息改为合成数据。安装包重新构建，逐项核对内容，不使用原开发环境的既有包。提交使用公开账号及 GitHub noreply 邮箱。

检查覆盖文件名、源码、说明文档、测试夹具和安装包内容，结合敏感格式扫描及人工核对。自动扫描不能替代部署者对后续新增数据的审查。

## 使用时的数据边界

本客户端接收真实材料后，会按用户确认的授权将材料传给部署者配置的研究后端。仓库脱敏不等于运行中的材料自动脱敏；后端保留期限、身份隔离、日志、模型提供方和材料使用许可需要另行配置与核验。

不要把密钥放进源码或公开问题；提交错误报告时使用合成材料，删去请求头、subject、操作句柄和签名地址。默认忽略规则是辅助措施，发布前仍需检查实际 Git 暂存区。
